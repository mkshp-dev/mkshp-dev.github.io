This Privacy Policy explains how Indian History Everyday Uploader (the "App"), operated by Mukund Shelake ("I", "me"), accesses, uses, stores and shares Google user data. The App is a private tool used only to upload videos to YouTube channels owned by its operator.

1. YouTube API Services

The App uses YouTube API Services. By using the App you agree to the YouTube Terms of Service. Google's own collection and use of data is governed by the Google Privacy Policy (http://www.google.com/policies/privacy).

2. Google user data the App accesses

When the account owner signs in with Google and grants permission, the App receives:

  • An OAuth access token and refresh token for the signed-in Google account, limited to the YouTube scopes listed below.
  • Basic YouTube channel information (channel ID and title), used only to confirm that uploads go to the right channel.
  • Information about videos the App itself uploaded (video ID, upload and processing status, privacy status and scheduled publish time).

The App requests only these scopes:

  • https://www.googleapis.com/auth/youtube.upload: to upload videos and their metadata.
  • https://www.googleapis.com/auth/youtube.readonly: to read the channel identity and the status of uploaded videos.

The App does not access Gmail, Drive, Contacts, comments, subscribers, viewing history, or any data of people other than the account owner.

3. How the data is used

Google user data is used only to provide the App's single feature: uploading the operator's own approved videos to the operator's own YouTube channel and checking that they uploaded correctly. It is not used for advertising, profiling, analytics, selling, or training machine learning or AI models.

4. Limited Use

The App's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Storage and security

  • OAuth tokens are stored in a private, access-restricted file on the operator's own server. They are never written to a public repository, website or log.
  • Upload results (video ID, status, publish time) are stored in the operator's private content database so that each daily video can be tracked.
  • Connections to Google use HTTPS. Access to the server is restricted to the operator.

6. Sharing

Google user data is not sold, rented or shared with any third party. It is sent only to Google's own YouTube API in order to perform uploads. It may be disclosed only if required by law.

7. Retention and deletion

Tokens are kept only while the App is in use. You can revoke the App's access at any time from your Google Account at https://myaccount.google.com/permissions (also reachable at https://security.google.com/settings/security/permissions). After access is revoked, or on request by email, stored tokens are deleted within 7 days. Upload records about videos on the operator's own channel are kept as part of the channel's publishing history and can be deleted on request.

8. Cookies and this website

These web pages set no cookies, use no analytics and collect no personal information from visitors.

9. Children

The App is not directed to children and is used only by the channel's adult owner.

10. Changes

If this policy changes, the new version will be posted on this page with a new effective date.
